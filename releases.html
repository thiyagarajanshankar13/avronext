What's new in AvroNext

Phone menus, labels and attachments

4 November 2026

New Section menus as icon chips on phones

The ☰ menu button is gone. On a phone, each section's menu (Board / List / Project settings, the Files views, Notes labels, Space settings, Administration) is now a row of icon chips under the title bar. The row stays put while you scroll and scrolls sideways when it doesn't fit, so every screen is one tap away.

In a space, the page tree opens as a bottom sheet from the new Pages chip.

New Create labels while you label an issue

  • The issue panel's label menu has a New label box at the bottom: type a name and press Add. The label is created for the project and put on the issue straight away.
  • The Create issue dialog's label picker has New label…, and the Labels field now shows even when the project has no labels yet.
  • Typing a name that already exists reuses that label instead of making a duplicate. New labels take the next colour from the project palette.
  • Like in Deck, creating labels needs the project's manage permission; everyone else can still pick from the existing ones.

Improved Bigger search button on phones

The search icon in the phone title bar is larger and has a full-size tap target.

Fixed Attaching files to issues on Nextcloud 33 and 34

On newer Nextcloud servers every upload to an issue failed with Nextcloud returned 400. Deck for Nextcloud 33/34 expects a data field with each upload, and Nextcloud rejects the request before Deck runs when it's missing. AvroNext now sends it, and older Deck versions keep working. Sharing a file into a new issue from the phone share sheet uses the same upload and is fixed too.

If an upload failed before you updated, press Dismiss on it and attach the file again.

Notes and the mobile app

1–3 November 2026

New Keep-style Notes

  • Notes are stored exactly like the Nextcloud Notes app, as Markdown files in your own Notes folder, so both apps work on the same notes. No database.
  • Checklists, pinning, archive, colours, labels, images and sharing.
  • Notes are kept in your browser and sync in the background, so they open instantly and survive a lost connection. If two devices change the same note, both versions are kept.

New Installable mobile app (PWA)

  • Install from the profile menu (iPhone: Share → Add to Home Screen).
  • Phone layout with a bottom tab bar, a + button for each screen, bottom sheets and full-screen issues.
  • App-icon shortcuts for New note, New issue and Upload. On Android you can share photos, files and links from other apps into Files, a note or an issue.

Improved Projects

  • The Create issue dialog has the full rich-text editor for the description.
  • Avatars without a photo show coloured initials. The board's assignee filter shows faces with a +N menu instead of names.

Fixed Logout behind Docker and Railway

Logging out (and some login redirects) sent you to the server's bind address, such as 0.0.0.0:8080/login. Redirects now use the address your browser used.

First public release

31 October 2026

AvroNext goes open source under AGPL-3.0: Jira-style projects on Nextcloud Deck, Confluence-style spaces on Collectives, OneDrive-style Files with a built-in viewer for PDFs, images, video and Office files, people and administration, light and dark themes. See the feature tour.

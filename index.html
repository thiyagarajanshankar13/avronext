Get started

1 What you need

  • Nextcloud 28 or newer with the Deck and Collectives apps (Teams/Circles ships with Nextcloud). The Notes app is optional.
  • Docker, or Node.js 20.9+
  • HTTPS in front of AvroNext (needed for secure sign-in cookies and to install the mobile app)

2 Run it with Docker

git clone https://github.com/thiyagarajanshankar13/avronext.git
cd avronext
docker build -t avronext .
docker run -d --name avronext -p 3000:3000 \
  -e NEXTCLOUD_URL=https://cloud.example.com \
  -e SESSION_SECRET="$(openssl rand -base64 48)" \
  avronext

Put it behind your HTTPS reverse proxy (Caddy, Nginx, Traefik…) and open it. Trying it on plain http away from localhost? Add -e COOKIE_SECURE=false.

…or Deploy on Railway

  1. Fork the repo on GitHub.
  2. In Railway: New project → Deploy from GitHub repo → pick your fork. Railway builds the Dockerfile automatically.
  3. Under Variables, add NEXTCLOUD_URL and SESSION_SECRET (32+ random characters).
  4. Under Settings → Networking, click Generate domain. You get HTTPS automatically.
  5. Open the domain and sign in with your Nextcloud account.

…or Run it with Node.js

git clone https://github.com/thiyagarajanshankar13/avronext.git
cd avronext
cp .env.example .env    # set NEXTCLOUD_URL and SESSION_SECRET
npm install
npm run build
npm start               # http://localhost:3000

Settings

VariableRequiredWhat it does
NEXTCLOUD_URLyesYour Nextcloud, as the AvroNext server reaches it, e.g. https://cloud.example.com
SESSION_SECRETyes32+ random characters that encrypt the sign-in cookie (openssl rand -base64 48)
NEXTCLOUD_PUBLIC_URLnoNextcloud's address as browsers see it, if different (e.g. an internal Docker hostname above)
MAX_UPLOAD_MBnoLargest issue/page attachment per file (default 100). Files uploads are chunked and have no AvroNext limit.
COOKIE_SECUREnotrue in production; set false only for plain-http testing away from localhost

Signing in

Continue with Nextcloud uses Nextcloud's Login Flow, so two-factor and SSO keep working and AvroNext never sees your password. Or sign in with a username and password, which is swapped for an app password straight away. Log out revokes it.

Installing on your phone

Android / Chrome / Edge: profile menu → Install app. iPhone / iPad: open AvroNext in Safari → Share → Add to Home Screen. It opens full screen with its own icon.

FAQ

Does AvroNext store my data anywhere?

No. It has no database and keeps no files. Every project, page, file and note lives in your Nextcloud. The only things kept are an encrypted sign-in cookie, your theme choice and, for Notes, a copy in your own browser so it opens instantly and works offline.

Can I keep using Nextcloud's own apps?

Yes. AvroNext uses Deck, Collectives, Files and the Notes app's own formats, so changes in either place show up in the other.

Do I need Nextcloud Office to open documents?

No. Word, Excel and PowerPoint files are shown read-only in the browser by AvroNext itself, along with PDFs, images, video and text.

What happens if I go offline?

Notes keep working: edits are saved in your browser and synced when you're back online. Other screens need a connection and show a friendly offline page.

Who can see what?

Exactly what Nextcloud allows. AvroNext signs in as each person with their own app password, so Nextcloud's permissions, sharing and group rules apply everywhere.

Is it free?

Yes, under the GNU AGPL-3.0, the same licence as Nextcloud. If you run a modified version as a service for others, you share your changes with them.
